# 出張報告（2025国際ロボット展）

2025年12月3日（水）  
東京ビッグサイト（東4〜8ホール・西1〜4ホール）  

## 展示会概要（補足）

- 名称：2025国際ロボット展（INTERNATIONAL ROBOT EXHIBITION 2025）  
- 会期：リアル会期 2025年12月3日（水）〜12月6日（土）10:00〜17:00  
  オンライン会期 2025年11月19日（水）〜12月19日（金）  
- テーマ：「ロボティクスがもたらす持続可能な社会」  
  人とロボットの共存・協働による産業創出と社会課題の解決を掲げる、世界最大級のロボット専門展。

## 目的

ROS 2 を用いたロボットおよびロボットコンポーネントについて最新動向を調査し、当社導入の資料とする。とくに、3 kg 可搬クラスの協働ロボットの選定を念頭に置いた。

## 展示の様子

ROS 2 を大々的に前面に出しているブースは多くないが、NVIDIA Isaac Sim や RViz を用いたシミュレーション／デモ表示から ROS 2 の利用を感じ取れる展示はいくつか見られた。  
説明員とのやり取りから、各社とも ROS 2 対応やサポートに関する問い合わせが多いことがうかがえる。  
さらに詳しい技術的な内容は、ROS 2 の知識が豊富な技術一課・和田さんのレポートを参照されたい。

### 各社ブース（ROS 2 観点）

#### [Techman](https://www.tm-robot.com/ja/)

- Techman 公式の ROS 2 用 GitHub リポジトリあり。ROS 2 Foxy / Humble 向けのドライバが提供されており、TMflow との連携や MoveIt / Gazebo 用のモデルなど、基本的なリソースは一通りそろっている（Web 情報）。  
- 国内では複数の商社・SIerで取り扱いがあり、ROS 2 を使う前提であれば、どの商社経由でも大きな差はないと考えられる。  
- 価格は 400 万円程度と高価だが、公式ドライバとドキュメントがあるため、導入後の技術的な安心感は高い。

#### [Universal Robots](https://www.universal-robots.com/ja/)

- 当然 ROS 2 対応。従来は有志コミュニティによるライブラリが目立っていたが、現在は Universal Robots 公式から ROS / ROS 2 Driver（`ur_robot_driver` など）が提供されている（Web 情報）。  
- PolyScope X v10.7.0 以降のコントローラでは、ロボット本体側に ROS 2 機能が内蔵されており、状態トピックの配信や I/O 制御などをドライバ無しで行えるモードも用意されている（Web 情報）。  
- 一方で、有志による GitHub リポジトリやサンプルも引き続き充実しており、具体的な適用例やノウハウはコミュニティの方が豊富な側面もある。  
- 販売代理店の中には ROS 2 を得意とする SIer がおり、ここを通して購入すれば ROS 2 に関する技術サポートも期待できる。  
- 価格は 400 万円程度。

#### [ミスミ FAIRINO](https://jp.misumi-ec.com/maker/fairino/mech/product/cobot/)

- FAIRINO は中国のメーカーだが、デンソーをはじめ国内の大手製造業にも導入実績があるとのこと。グローバルの販売台数では Universal Robots を上回るという説明があった。  
- ROS 2 に対応しており、FAIR-INNOVATION 公式の ROS 2 API プロジェクト（`frcobot_ros2`）が GitHub 上で公開されている。Fair SDK API をラップしたサービスインタフェースを提供し、ソフトウェアバージョン 3.7.1 以降で利用可能とされている（Web 情報）。  
- 価格は 75 万円程度と安価で、ミスミ取り扱いらしく納期も短いとのこと。12 月 16 日にミスミで開催されるデモで、ROS 2 ライブラリの中身やサポート範囲をより詳しく確認予定。

## まとめ・所感

- ノーマークだったミスミ FAIRINO を新たに発見。中華メーカー FAIR-INNOVATION の製品だが、国内はミスミ経由でのサポートが期待できるため安心感はある。  
- Techman / Universal Robots は価格帯が高い一方で、公式 ROS 2 ドライバやドキュメントが充実しており、長期的な保守性・拡張性という意味での優位性がある。  
- FAIRINO は価格・納期面で圧倒的に有利であり、ROS 2 ライブラリおよびドキュメントの充実度次第では、3 kg クラス協働ロボットの有力候補となり得る。
