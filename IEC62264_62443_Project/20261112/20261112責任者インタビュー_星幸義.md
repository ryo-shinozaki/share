## インタビューの目的・記録上の扱い

2030年に向けた工場の将来像とDXの方向性を検討するため、工具開発・製造技術の立場から、業務の実態、品質上の課題、自動化への期待を把握する。AS/400を含むシステムの将来像だけでなく、業務・設備・管理方法も対象とし、Phase0の課題整理につなげる。

## 1. 要旨

- 第一工具技術部はPCBドリルの開発・改良だけでなく、顧客の加工環境の把握、穴あけ評価、量産可否の検証、品質トラブル対応を担う。生産技術部が設備を設計・開発し、工具技術側は製品仕様や量産性の観点から関与する。
- 開発は、形状設計の経験・判断と、実物を試作して穴あけ評価する実験的な進め方が中心。顧客との試行錯誤を経て、サンプル評価から少量産・量産へ進めている。
- 品質課題は、工程で不良と判定・処置される比率、管理基準から外れた製品の流出、管理基準内でも起きる顧客での折損を区別する必要がある。
- BDIの約5%という不良・アウト率には、設備停止等により品質に確信が持てないロットをまとめて不良処置する運用が影響している。良品の可能性が高いものも含まれ、原因確認・再判定に必要な人員が不足しているとの説明があった。
- 星部長が重視するのは、重要形状のばらつきを抑え、顧客使用時の折損を防ぐこと。特にウェブ厚・ウェブテーパーを管理中心へ維持する自動補正を望んでいる。
- 個体単位で工程情報をつなぎ、不良の影響範囲を絞ることが改善案として議論された。検査技術の開発が必要な問題と、既存の管理・データ活用で改善できる問題を分けて検討する方向が示された。

## 2. 星部長の経歴・担当部門の役割

### 2.1 経歴

2001年入社。入社以来、PCBドリルの開発を中心に従事。最初の約6年間は、海外顧客に対する技術営業を担当した。顧客が達成したい目標と実際の加工環境を把握しなければ適切な工具を開発できず、営業技術的な活動は重要と捉えている。

その後、DLCコーティングを用いたドリルの開発・量産化に携わった。原文のコーティング名称は「ウルフコート」等に揺れているため、正式表記は要確認。外部から提案されたコーティング技術を評価し、コーティングを活かす工具設計も含めて基礎を確立したとの説明があった。

2013年に課長となり、工具開発全体を管理。第3世代ラインの量産管理方法や、第4世代設備の基本構造に関する検討にも関与した。現在は増産を背景に、第3・第4世代で効率よく生産するための製造技術面の業務にも重点を置いている。

## 3. 開発区分・設計文書・量産への流れ

### 3.1 工具の開発ルート

面談では、工具のルート判定と設備のルート判定が別であることを確認した。以下は工具についての口頭説明であり、正式な定義・適用条件は規程で確認する。

| 区分 | 発言上の位置づけ |
| --- | --- |
| ルート1 | PCBドリルの既存の枠組みを外れるような、新規性が特に高いもの |
| ルート2 | 製作可能領域外の仕様、既存設備を使っても従来とは大きく異なる形状、量産条件が確立していないもの等 |
| ルート3 | 既存の製作可能領域内で、過去に用いた設計手法による新規性の低い形状・改良等 |

ルート2は量産試作・DR（デザインレビュー）の対象、ルート3はDRを行わないとの説明があった。ルート1の具体的な審査フローは本面談では十分確認できていない。

### 3.2 設計・条件設定に用いる情報

試作図には、刃の形状、材質、使用するアセンブリー仕様等を示す。アセンブリーは、シャンクと超硬材料を接合したものの仕様を指し、多くの種類がある。

工具技術側では、製作可能領域表、アセンブリーの種類を示す表、超硬材料の特性・仕様に関する資料を作成する。各工程の製造条件をすべて工具技術部から発行するわけではなく、製造部門の標準類や技術開発課のコーティング条件等と分担している。

### 3.3 試作・評価の進め方

1. 顧客要求、加工対象の基板・材質、使用環境等を把握し、工具の形状・材質等を検討する。
2. 試作班が工具を製作する。形状を決める段階では、経験や判断の差が出やすい。
3. 社内の穴あけ評価設備で性能を確認する。顧客から預かった基板や近い材料を使い、加工した穴の品質も評価する。顧客へ加工条件を提案する場合もある。
4. 顧客へサンプルを提出し、結果を基に再設計・再評価する。一度で成立する例は少なく、3～4回程度の試行錯誤を行うことがある。
5. 少量産で製造・性能を評価し、必要な区分では量産試作・DRを行う。

材料選定で迷う場合は複数の候補を実際に試す。CAD等によるシミュレーションは相対的に弱く、実物を作って加工評価した方が早く結果が得られるという開発スタイルを長年取っている。社内で顧客に近い環境の評価ができる一方、評価には時間がかかる。

サンプルは概ね1,000本以内、少量産は1万～2万本程度との説明があった。ただし、折損評価の説明では1,000～2,000本の例も挙がっており、すべての開発で同一の本数を用いるわけではない。

### 3.4 量産移行の評価

管理項目の工程能力を基に判断し、条件を満たせない場合には良品率90%以上等で判断するケースもあるとの説明があった。工程能力の基準値は原文で「33」となっており、正確な値・指標は確認する。

良品率90%程度で進める対象の例として、細く長い高アスペクト比のドリルが挙げられた。従来の溝長が直径の20～30倍程度であるのに対し、40～50倍程度の要求もあり、顧客との関係や事業機会、立ち上げの緊急性を踏まえ、製造・品質保証も事情を共有して判断する場合がある。

これは製造時の歩留まりを踏まえた判断であり、不適合品をそのまま出荷してよいという意味ではない。

## 4. 品質を捉える際に区別すべき三つの問題

| 観点 | 面談での説明 | 改善の着眼点 |
| --- | --- | --- |
| 工程内の不良・アウト率 | 設定した公差・管理ルールに基づき不良処置する割合。疑わしいロットの一括処置も含む | 真の不適合と安全側の処置を分け、原因・影響範囲・判定負荷を確認 |
| 管理基準から外れた製品の流出 | 異径品の混入、ラベル誤り、公差外等。本来の管理で止めるべき問題 | 管理・検査・識別を確実に実施し、流出を防ぐ |
| 基準内の製品で起きる顧客トラブル | 工場の管理基準を満たしていても、顧客使用時に折損等が起きる問題 | 管理項目・公差・重要形状のばらつきを見直し、性能を作り込む |

星部長は、単に工程内不良率を下げること以上に、公差・管理幅を狭めることも含め、顧客でトラブルを起こさない工具を出したいとの考えを示した。管理基準内であっても性能に影響するばらつきがあり、現在の不良率だけでは顧客での性能を十分に表せない。

一方、管理基準を守れていない製品の流出については、基本として防ぐべき問題と認識している。参照したクレーム一覧には、主としてこの種の事例が含まれるとの説明であり、基準内での性能問題とは同一視しない。

## 5. BDIの不良・アウト率と個体管理の可能性

### 5.1 約5%の内容

BDIはブランク加工・中間検査・歯切りが連続している。従来の第3世代までと異なり、設備内でチョコ停等が起きると、どの製品が影響を受けたかを把握しにくくなる場合がある。

品質上疑わしいロットは全体を不良処置するルールがあり、そのような処置が約5%のアウト率の多くを占めるとの説明があった。ブランク加工の管理値が限界付近にある場合等も、ロットを安全側に処置する例として挙げられた。

実際に不適合となっているものは約1%程度という発言もあったが、集計資料で確認した実測値とは限らない。約5%と約1%の差を、そのまま確実な改善効果とは扱わない。

### 5.2 改善を進められない理由

星部長は、この問題の改善方法は分かっており、検討にも関わってきたが、現在はリソースの問題で対応できないと説明した。良品の可能性が高いものでも、原因や品質への影響を確認して良否を判断するには、検査・調査に人が必要となる。

### 5.3 個体単位での情報連携

現在は塊・ロット単位で扱う部分が多く、工程によっては製品の順番も崩れる。最初から1本単位で識別でき、工程情報とつながれば、不良の影響範囲を絞って後工程で対象品だけを取り除くことも考えられるとの議論があった。

切断・接合の段階から個体管理を開始する案も挙がった。ただし、識別方法、設備・システムの実現性、費用対効果は未検証であり、個体管理の導入を決定したものではない。

## 6. 顧客での折損と重要形状の安定化

### 6.1 折損評価の前提

顧客の折損率の規格は、例として0.1～0.5%程度との説明があった。0.1%は、所定の使用条件・ヒット数で使用するドリル1,000本に対し、折れるものが1本という考え方である。顧客・製品によって評価条件は異なる。

ヒット数は基板や加工難易度により数百回から1万回程度、加工性のよいものでは2万回程度まで幅がある。細く長いドリルでは使用ヒット数も少ない。異なる基板・用途のヒット数を、そのまま工具性能の優劣として比較できない。

顧客での折損には工具側と顧客側の両方の要因があり、星部長は自社起因の不良をさらに低く、0.01%やppmオーダーにしたいとの希望を示した。原因の半分が工具側とする例や0.05%の数値は説明上の仮定であり、原因別実績・正式目標ではない。

### 6.2 管理幅の中で動く製造から、中心を狙う製造へ

星部長は、現在の製造は「管理幅の範囲内なら変動してよい」という考え方になりやすいと指摘した。砥石は使用とともに摩耗・変形し、加工される形状も変化するため、常に管理中心を狙い続けることは難しい。

現在は人が傾向を見て中心へ寄せる調整をしているが、特に重要な形状項目について、自動で補正する仕組みを望んでいる。面談ではブランク径の補正と、今回要望している歯切り形状の補正を区別した。

### 6.3 ウェブ厚・ウェブテーパー

ドリルの二つの溝の間に残る肉の厚み（ウェブ厚）は、工具の強度と切りくず排出性を左右する。薄すぎれば強度が不足し、厚すぎれば溝の容積が小さくなって切りくず排出が悪化するため、どちらも折損につながり得る。

先端から根元へ向かうウェブ厚の変化（ウェブテーパー）も性能に重要。砥石の摩耗によるこれらの変動を抑え、適切な状態へ自動補正できる仕組みが求められている。

### 6.4 砥石交換と生産能力のトレードオフ

砥石交換のタイミングは、加工したドリル形状が公差・管理値に入っているかを基に決まる。管理幅を狭めれば交換頻度を上げる方向になるが、主な制約は砥石自体の費用よりも、設備停止と作業人員の負荷である。

歯切りはボトルネック工程であり、交換等で止めると生産量が落ちるため、製造側から反対されやすい。一方で突発的な品質トラブルは大量の対応工数を要することがあり、平常時の生産効率と品質リスクの両面で検討が必要との議論となった。

## 7. 検査の範囲・技術的制約と流出防止

### 7.1 全数検査で見ているもの

全数検査という説明は、主にドリルを先端方向から見た形状を対象とする。性能上重要な側面形状を歯切り後に全数確認する工程はなく、側面からの測定は工程内・出荷時の抜き取りが中心との説明があった。

面談中に「出荷検査で横は見ない」との発言もあるが、その後、出荷検査時にも側面の抜き取り測定を行うと補足されている。自動画像検査と人・測定器による抜き取りの区分、対象項目はQC工程表等で確認する。

### 7.2 側面・溝形状の全数測定の難しさ

側面や溝底・深さの確認は画像取得自体が難しく、時間もかかる。抜き取りで許容される測定時間で確認する方法はあるが、量産サイクルに合わせた全数測定への展開は容易ではない。

照明を工夫して溝を撮影できても、それだけで深さまで測れるとは限らない。画像取得・測定原理・処理速度等に技術的な課題があり、ブレイクスルーが必要との意見が出た。特定方式の採用や全数化を決定したものではない。

### 7.3 材料・外注工程を含む品質管理

材料内部の異物や巣、外周傷等も問題となる。破断面に内部欠陥があれば材料側、外周加工で付いた傷であれば加工側というように、原因を確認する必要がある。チップ側の外周加工には外注先が関わっているとの説明があった。

材料メーカー等から出荷後に欠陥の連絡が来る場合や、工程飛ばしの例にも言及があった。ただし、工程飛ばしはまれであると補足されており、頻発しているとは記載しない。外注加工を内製化する可能性にも触れたが、面談では現行の経緯・適否の検証や変更決定はしていない。

## 8. データ活用・今後の検討事項

面談では、測定技術そのものの開発が必要な課題と、既存の管理を確実に実施し、監視・データ連携で防げる課題を分けて検討する方向が示された。データがまとまっておらず、必要なときにアクセスできないことが改善を妨げているとの意見も出た。

| 検討・確認項目 | 内容 | 面談での扱い |
| --- | --- | --- |
| 開発ルートとDR | 工具用の正式なルート定義、ルート別の試作・量産移行・審査フロー | 規程類を参照。設備用の定義との混同に注意 |
| 量産移行基準 | 工程能力の指標・閾値、良品率90%等で進める場合の適用条件・判断記録 | 工程能力の数値は聞き取り不明瞭で要確認 |
| BDIのアウト率 | 約5%の内訳、真の不適合、疑わしいロットの一括処置、原因・判定に必要な工数 | 星部長から現状説明。定量資料での裏付けが必要 |
| 個体管理 | 識別の開始点、工程間での順序変化、個体と加工・検査情報の対応、不良影響範囲の限定 | 改善案として議論。方式・費用対効果は未検証 |
| 重要形状の管理 | ウェブ厚・ウェブテーパー等の目標、管理幅、測定・補正方法、砥石摩耗との関係 | 星部長から自動補正への要望あり |
| 流出防止 | 混入・ラベル誤り・公差外等の発生と流出原因、工程内・出荷検査の対象と役割 | 基本的な管理として改善が必要との認識 |
| 検査技術 | 側面・溝深さの測定精度と時間、抜き取りと全数化の制約 | 技術開発課題としての切り分けを議論 |
| 材料・外注品質 | 内部欠陥と加工傷の原因区分、検査・供給者管理、欠陥連絡時の影響範囲 | 原因・管理実態の追加確認が必要 |
| 品質指標 | 工程内不良率、ロット処置率、流出不良、顧客折損率を区別した定義・集計 | 本面談の議論を踏まえた確認事項 |

品質の検討テーマが具体化した段階で、追加で話を伺う可能性が示された。本面談では、個別施策の実施、管理基準変更、個体管理の導入、担当者・期限の確定は確認できない。終盤の優先順位に関する発言には画面・図への指示語が多く、厳密な順位は確定しない。
