## インタビューの目的・記録上の扱い

AS/400をはじめとするシステムの最適化に向け、生産管理業務の実態と課題を把握する。部門ごとの改善だけでなく全体最適の視点から課題ロングリストを作成し、今後のロードマップ検討につなげる。

## 1. 要旨

- 需要が供給を上回り、PCBドリルの受注残は約6,000万本、先月の生産は約2,400万本、在庫月数は約0.5か月との説明があった。増産しても出荷需要が大きく、在庫を積み増せていない。
- Asprovaで設備・号機別に詳細な計画を立てているのは主に歯切り工程まで。後工程の洗浄、コーティング、検査、詰め替え、梱包・出荷までを一貫して計画・管理する仕組みが弱い。
- MotionBoard等で設備の予実や出荷不足を可視化しているが、必要な製品が出荷まで進まない。生産管理一課が朝・昼に状況を調べ、メールで優先処理を依頼する業務が大きな負担になっている。
- BDIの中間検査では、油の付着による測定誤差で良品が不良判定される問題がある。約5%との説明があり、再測定を行うNラインとの運用差も示された。
- 和田課長が特に改善したいのは、計画どおりに進まないことで追加の調査・督促・調整業務が生まれる状態。自動化による課員の負担軽減にも期待している。
- 和田課長から、各工程の設備能力を踏まえた標準リードタイムを確認して後日送付する申し出があった。代表ロットの工程完了履歴を用いた実績確認も依頼された。

## 2. 経歴・担当業務と関係部門

### 2.1 和田課長の経歴

2009年入社。技術部門でPCB工具、特にパッケージ基板の穴あけに用いるドリルの開発・設計や技術営業に従事してきた。2026年1月に生産管理一課へ異動した。

### 2.2 生産管理一課の担当範囲

- 営業からの需要情報を基にした需要予測・生産計画の取りまとめ。
- 生産指示、進捗の全体把握、営業・製造との調整。
- 製品に使用する材料の外注管理。
- 設備増設の予定・進捗を確認し、遅延がドリル生産に与える影響を把握すること。

一課はドリル等の切削工具製品の生産管理、二課は設備側の管理を担当する。設備部品の調達は資材課が担当し、設備の計画・進捗情報を二課から共有してもらい、一課が製品生産への影響を製造部門と確認する。現在は増産に伴う設備導入が多く、部品遅延等による設備計画の変更について、日々確認・調整が発生している。

## 3. 需要予測・生産計画・納期回答

### 3.1 計画の階層と使用ツール

| 計画の範囲 | 現在の進め方 |
| --- | --- |
| 中長期 | 2030年頃までの増産見込みを整理し、材料メーカーへフォーキャストを提示して供給確保を依頼 |
| 年次 | 9～10月頃から翌期計画を作成。営業が顧客需要を集め、製造と調整して生産計画・設備増設計画へ反映 |
| 月次 | 年次計画から月次の生産計画へ落とし込む。設備立ち上げ等の状況に応じて見直す |
| 週次・日次 | Asprovaでセット計画等を作成し、製造と共有。確度のある詳細計画として管理している範囲は概ね2か月先まで |

営業がポータルへ受注情報を入力し、そのデータをExcelへ取り込んでAsprovaへ反映する流れとの説明があった。ポータルの入力画面は面談時に十分確認できていない。

### 3.2 需要超過と受注残

設備増設は可能な限り最大の計画を立てているものの、需要を満足する供給量には届かない。顧客からの要求数量も上振れしている。新規案件を断る場合がある一方、継続顧客の注文数量増加は断りにくく、受注が増えているとの説明があった。

面談時には、未生産の受注残が約6,000万本、先月の生産能力・生産実績が約2,400万本との発言があった。品目によっては納期回答が3～4か月先になるが、詳細な生産計画がそこまで組めているわけではない。

### 3.3 在庫と計画修正

PCBドリルの在庫月数は約0.5か月。生産・出荷ともに増えている一方、在庫月数は低下しており、作ったものを出荷へ充てる状態である。計画どおりに生産できても、需要との関係から在庫を増やすのは難しいとの認識が示された。

第1工場の立ち上げ遅延について、計画に入れた設備が予定どおりに稼働せず、画面説明では11月11日時点の達成率が約80%との発言があった。11月全体では約80万本の下方修正が必要となる見込みも示された。達成率の対象設備・工程と、数量修正の対象範囲は資料で確認する。

## 4. Asprovaの管理範囲と計画運用

### 4.1 設備・号機別の計画

PCBドリルは設備群別に計画を作成し、BDI等では号機ごとに1ロット1,000本の予定を割り当てている。ルーター等についても区分して計画しているとの説明があった。

Asprovaでは、型番ごとのサイクルタイムや設備条件を登録して計画する。対象設備で製造できるサイズ帯、顧客への4M変更申請・承認状況等の制約があるため、自由に設備を振り替えられるわけではない。

大口品は効率の高いBDI、小ロット品等はAD・Nライン等へ割り振る考え方が示された。ただし、型番別の製造可否や顧客条件を踏まえて選定している。

### 4.2 実績反映と遅延対応

号機別の画面には計画と実績が表示され、突発修理等による空き時間や予定のずれを確認できる。遅延すると後続の予定がずれ、納期を満たせない場合は生産管理側で予定の入れ替えや納期調整を行う。

生産開始・完了の時刻等はAS系のデータからほぼリアルタイムで反映されるとの説明があった。一方、元の登録には人の操作があり、完成本数等も入力しているとの認識が示された。設備からの完全自動収集と解釈せず、入力方法・連携先は別途確認する。

計画画面の色や空き時間には段取り・ドレス等が関係する可能性があるが、面談では一部推測を含む説明であった。最適化の目的関数や細かな設定は確定していない。また、数理最適化による改善を今期進めている旨の発言があり、対象範囲・実装状況は要確認。

### 4.3 後工程までの計画の不足

Asprovaの詳細なスケジュールは主に歯切り工程を対象とする。前工程はその予定に合わせて材料を供給するが、後工程は順次流す運用となっており、案件・ロットごとに出荷までの各工程の期限を一貫して示す計画は確認できなかった。

納期回答は生産管理側が歯切り予定を基準に、後工程に必要と見込む日数を加味し、営業経由で顧客に伝える。全工程に共通する標準リードタイムや、その構造を示した資料は面談時点で提示できないとの説明があった。

## 5. 生産が出荷に結びつかない問題

### 5.1 後工程の流れと滞留

歯切りまでの生産数を増やす取り組みは進んでいるが、その後の洗浄、コーティング、検査、リングセット、詰め替え、梱包・出荷へつなぐ動きが弱いと和田課長は捉えている。工程間の運搬やカセット形態の変更に伴う詰め替えも発生する。

工程内に物が多く、必要な製品を探すことにも手間がかかる。加工できた順に流しても、必ずしも納期順にはならない。工場間の運搬は1日1～2便程度との説明があり、運搬される製品に優先すべき型番が含まれていない例もある。

### 5.2 生産管理一課による毎日のフォロー

1. 朝、当日出荷予定に対し、まだ倉庫へ入っていない製品を確認する。
2. 型番別の不足ロット数と、各工程にある数量を洗い出す。
3. 関係工程へメールで連絡し、必要な製品を優先して、場合によっては手渡しで進めるよう依頼する。
4. 昼に再確認し、未入庫分について追加連絡・督促する。

一覧を作るためのツールやデータダウンロードの仕組みはあるが、実際に動いたかの確認と追加調整が必要である。それでも当日出荷に間に合わないものがある。和田課長は、このフォローが現在一課で特に時間のかかる業務であり、工程が計画どおり進めば不要になる仕事と認識している。

### 5.3 管理者から作業者への指示の伝達

優先連絡は出しているが、管理者から作業者へ指示が行き届いていない可能性や、認識していても手が回っていない可能性がある。作業者にはメールを持たない人もおり、班長以上等へ送る運用となっている。現場全体へ優先順位が浸透しているかは確認できていない。

連絡未確認、指示の未伝達、人手不足、設備トラブル等のどれが主因かは、本面談では特定していない。

## 6. 可視化の現状と不足している情報

### 6.1 MotionBoardによる可視化

BDIやNライン等について、工場・拠点をまたいで、設備稼働状況、リアルタイムの計画・実績・達成率、月次数量や前日までの実績を確認できる。達成率の悪化等は色でも判別できる。

出荷不足を確認するボードでは、当日出荷予定に対する不足と、型番ごとに各工程に何本あるかを一覧表示している。倉庫在庫や完成入力に関するデータは、AS/400の日報等から取得しているとの説明があった。

面談時の画面では、当日出荷予定約120万本に対し、梱包済み約40万本、午後に対応が必要な数量約75万本との発言があった。端数・確認時点等のため単純計算とは一致せず、正確な数値は元資料で確認する。

### 6.2 ロット単位の追跡と全体進捗の違い

個別ロットを調べるツールや、不具合発生時に履歴を追跡する仕組みはある。一方、全ロットについて、前後工程を含む計画と実績を一括で把握できる画面・一覧はないとの認識が示された。

各工程の課長はそれぞれ管理しているが、後工程の管理は各部署に任せている部分もある。設備別の予実や工程別の数量が見えていても、それだけでは出荷納期に沿った全体の進行を保証できていない。複数の画面・ツールに情報が分散していることも話題となった。

## 7. 中間検査の不良判定・歩留まり

### 7.1 BDIの測定誤差による損失

BDIのブランク状態の中間検査では、加工と検査をつないだ構成で間に洗浄を挟まないため、油の付着による測定誤差が主な問題となっている。エアブローで除去しているが、十分に測定できない場合がある。洗浄して測れば良品になるものがあるとの説明があった。

技術側で改善に取り組んでいるが、今年は不良判定が約5%前後で、新設設備でも同様の問題があるとの認識。約60万本を不良として落としているとの発言もあったが、集計期間・対象設備は要確認であり、全数が誤判定と断定するものではない。

### 7.2 Nラインとの運用差

Nラインは洗浄後に別の中間検査設備で再測定し、問題がなければ良品にできる。一方、BDIは生産数を優先し、現状は再測定を除外して生産していると思うとの説明があった。BDIの不良判定品の最終処置や再測定の実施条件は、製造側で確認する必要がある。

### 7.3 良品率と生産指示への織り込み

Nライン・AD等について、全工程を通した良品率は概ね97～98%、工程単位では99%程度との認識が示された。BDIはまだ理想的な状態に達していない。これらは発言者の概算・認識であり、実績値は工程・製品別資料で確認する。

不良による数量減少を見込み、注文数量より多めに生産指示を出している。例として、1万本の注文に対し1万1,000～1万2,000本の指示を出す説明があったが、全製品共通の上乗せ率と解釈しない。

## 8. リードタイムの整理と仕掛かりの考え方

### 8.1 面談中に示された概算

面談では、実際に加工する時間と、待ち・運搬等を含む工程通過日数が混在していることを確認した。以下は仮の目安であり、標準値として確定したものではない。

| 対象 | 発言上の目安・留意点 |
| --- | --- |
| 全体の流れ | 起点によって約2週間との発言あり。アセンブリ等の在庫があり、その工程を除けば、ブランクから歯切り・コーティング・検査・出荷まで最短で1週間強程度との見方 |
| 現在の受注対応 | 予定が2か月先まで埋まっており、現在は1か月では対応できないとの説明。加工開始後の通過時間とは区別が必要 |
| 歯切りの1ロット | 約3～4時間という概算。型番別のサイクルタイムをAsprovaに登録して計算 |
| 切断・接合等の前工程 | 日単位で、約2日程度という会話上の概算。正確な所要時間は未確認 |
| コーティング | 工程通過として約1日、実処理時間として約8時間との説明 |
| コーティング後の先端研磨・検査 | 工程通過として約1日、研磨の実処理は約2～3時間との説明。設備名は要確認 |
| 外観検査・出荷検査 | 約半日という概算 |
| リングセット・詰め替え | 約半日～1日という概算 |

標準加工時間の合計、待ち・運搬を含むリードタイム、受注から着手までの待ちを分けて把握する必要がある。コンサルティング側からは、工程間の滞留を減らし、スムーズに流れる状態を目指すため、両方の時間を確認したいとの意向が示された。

### 8.2 実績から確認できること

ロットを絞れば、前工程の完了時点から当該工程の完了時点までの履歴を確認できるとの説明があった。これは当該工程の開始・終了時刻を直接示すものとは限らず、待ち時間を含む。

極端な異常例だけにならないよう、標準的なロットを複数選び、工程別の実績を確認することが提案・依頼された。

### 8.3 必要な仕掛かりの確保

和田課長は、現状でもリードタイムを短縮する努力をしている一方、短くしすぎると小さなトラブルで材料待ちが発生することを懸念している。工程が止まらないよう、一定の工程間在庫・仕掛かりは必要との考えが示された。必要量は本面談では定量化していない。

## 9. 改善への期待と追加確認事項

和田課長は、生産管理の立場では「計画どおりに進まないこと」が最もつらく、その結果として課員が追加の調査・連絡・調整に時間を使う状態を変えたいと述べた。調整のうち自動化できる部分があれば、課員の負担軽減につながることを期待している。

| 項目 | 内容・面談での扱い | 担当・期限等 |
| --- | --- | --- |
| 標準リードタイム | 各工程の設備能力を加味した正確な情報を確認し、後日送付すると和田課長から申し出あり | 和田課長。提出期限は明示なし |
| 代表ロットの実績 | 複数の標準的なロットについて、各工程の完了履歴から通過時間を確認するよう依頼 | 和田課長側へ依頼。対象ロット・提出方法・期限は未確定 |
| 面談中に参照した資料・ファイル | 歯切り工程・設備区分等が分かる資料について共有依頼あり。計画画面は送付済みとの発言もあり | 提出済み資料と追加提供対象の切り分けが必要 |
| 後工程の管理実態 | 工程ごとの計画、優先順位の決め方、責任者、現場への指示・引き継ぎ、未完了時の対応 | 関係する製造部門等への追加確認事項 |
| 工程経路・設備 | 型番ごとの工程経路、設備群・工程コードの意味、前後工程の設備能力・台数 | まず工程・設備区分を把握したいとの要望あり |
| 不良判定と再測定 | BDIの約5%・約60万本の定義と期間、誤判定の割合、再測定の可否、最終処置 | 製造・技術等の関係部門で確認が必要 |
| データ連携と入力 | ポータル→Excel→Asprovaの流れ、AS系の開始・完了登録、MotionBoardの取得元・更新頻度 | 面談では全容未確認 |
| 数理最適化の取り組み | 今期実施中との発言があった改善の対象と進捗 | 詳細は要確認 |

標準リードタイムの追加送付等を除き、個別の改善施策、システム導入・改修、担当・期限を確定した記録はない。後工程が進まない原因の特定と具体策は、追加資料・現場確認を踏まえて検討する。
