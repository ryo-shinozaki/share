## 1. インタビューの目的

Phase0の現状把握として、第一営業部の業務・これまでの取り組み、営業から見たものづくりの強みと課題、2030年に向けた目指す姿、本プロジェクトへの期待を確認した。

日本能率協会コンサルティング（以下、JMAC）より、経営目標・事業特性を踏まえて改革課題を洗い出し、工場・全社の目指す姿について共通認識をつくった上で、DXコンセプトの設定につなげる進め方が説明された。工場の無人化や工程滞留の解消等は、今後の調査・討議に向けた仮説として示された。

## 2. 主な確認事項・課題認識

- 当社の強みは、ばらつきの少ない高品質なPCB工具を安定して量産できることである。営業は価格競争よりも、高多層基板・半導体パッケージ基板等の高付加価値分野を重視している。
- 足元では需要に供給が追い付かず、追加供給の依頼や新規の引き合いを断っている。営業・生産管理ともに納期調整の負荷が大きい。
- 見積りに必要な価格、販売実績、原価、市場・顧客情報等は存在するものの、システム・ファイル・担当者ごとに分散している。情報収集と承認根拠の整理に時間を要している。
- 7桁の製品コードを起点に、販売先・数量・価格・原価・生産状況等の必要情報を一度に参照できる状態が望ましい。
- 2030年に向けて、営業は大幅な増員をせず売上を2倍・3倍に伸ばすイメージを持っている。ただし、取扱量の増加に対するシステムの容量・処理速度・業務効率の確認と、納期調整負荷への対応が必要である。
- 工場内の効率化に加え、受注・営業業務からグループ全体をつなぎ、効率よく業務を行える仕組みを本プロジェクトで検討してほしいとの要望があった。

※本インタビューは現状・課題・期待の確認を中心とするものであり、具体的なシステム導入、数値目標、施策の実施を決定したものではない。

## 3. 議事内容

### 3.1 廣島部長の経歴・工場との関わり

- 2000年に米国子会社USユニオンツールへ入社。当時、同社工場はPCBドリルを月約200万本生産していた。
- 入社後約1年間、日本人駐在員の通訳、作業マニュアルの作成、機械修理等、工場現場に関わる業務を経験した。
- その後、長岡工場で約2年間、ドリルの各工程を約3か月ずつ回る研修を受けた。
- 入社4年目頃から営業に従事。国内営業を約5年間、その後は海外営業を中心に担当し、中国・東莞への約2年間の赴任も経験した。
- 現在、顧客を伴う工場見学の機会はあるが、製造現場との日常的なやり取りは多くない。
- 今年は製造・技術・生産管理等の部門責任者が参加する中長期のプロジェクトにも参画し、将来の目指す姿の検討を行っている。

### 3.2 第一営業部の組織・担当範囲

- 第一営業部は本社に置かれ、PCB工具を担当する。部内の課はPCB営業課の1課である。
- PCB営業課は、受注・出荷業務を担う国内係・海外係の計6名と、営業担当6名の計12名との説明があった。
- 営業担当は国内・海外で分けず、原則として顧客単位で担当し、その顧客の国内外の拠点を横断して対応する。顧客の海外展開に伴い、国別では対応しにくくなったことが背景にある。
- 若手は国内営業を5～6年程度経験し、その後、国内・海外の双方を担当できるよう教育している。
- 本社のPCB営業課が直接担当する国内顧客に加え、大阪・福岡・名古屋・長岡等の営業所が担当する顧客がある。
- 営業所は組織上、第二営業部に所属するが、PCB工具の販売活動は第一営業部の方針に沿って行う。第一営業部はPCB工具の販売を統括する。
- 海外には製造子会社と販売子会社があり、PCB工具の海外生産拠点として台湾・上海・東莞が挙げられた。

### 3.3 市場・顧客と営業方針

- 国内では主要なプリント基板メーカーに広く採用されており、シェアは非常に高いとの認識が示された。
- 海外シェアは約3割という話が出たが、販売量が伸びる一方で競合メーカーの生産量も増加しており、最新の公表値はその場では確認できなかった。
- 主な競合は中国・台湾メーカーであり、当社の半額程度の価格の製品もある。低価格品で対応できる市場を価格競争で取りに行く方針ではない。
- 注力するのは、高多層基板や半導体パッケージ基板等、工具の品質・精度が求められる高付加価値分野である。
- データセンター向け等の厚い基板では、細く長い工具が必要となる。折れにくく、回転時のぶれが少ない工具を安定して量産し、早期に供給することが重要である。
- 営業の役割は、顧客から情報を得て信頼関係を築き、工具を評価してもらう機会につなげることと、適切な価格設定により利益を確保することである。
- 足元では追加供給の依頼を断る状況が続いており、大手海外顧客からの引き合いも供給できず断る例がある。現在の強い供給制約は、特にこの1年ほどで顕著になっている。
- 半導体関連分野のシェアについて、現状は半分程度、供給できれば9割程度まで取れるのではないかとの見方が示された。これは廣島部長の概括的な認識であり、対象市場の定義や集計値を確認したものではない。
- 需要拡大への対応について、供給能力の制約に加え、市場情報の伝達や投資判断のタイミングに関する問題意識も話題となった。制約の原因を工場だけに帰するものではない。

### 3.4 製品の強み・顧客の評価ポイント

- 最大の強みは、ばらつきが少なく、安定した品質の工具を繰り返し量産できることである。図面の公差内であっても、その中で品質を安定させることが難しく、顧客から評価されている。
- 穴あけ工具としては、まず折れずに貫通穴を開けられることが前提となる。主な評価ポイントは以下の2点である。
  - 狙った位置に穴を開けられること（穴位置精度）。
  - 穴の内壁がきれいで、銅箔の伸び等による問題を生じさせないこと（内壁品質）。
- 求められる品質は、国内・海外の地域差よりも、顧客が製造する基板・製品の種類や加工難易度によって異なる。
- 半導体パッケージ基板等では、他社工具では折損や品質上の問題が生じ、当社工具が選ばれるケースがあるとの説明があった。
- JMACからは、将来の品質要求に備え、ばらつきに影響する加工条件等のデータを把握し、強みをさらに高めることも検討視点となるとの意見があった。

### 3.5 顧客との共同開発・専用型番

- 基板材料・製法・配線等の変化に伴い、新しい穴あけやルーター加工の課題が生まれる。これらは顧客と共同して開発し、量産化まで2～3年程度かかる場合がある。
- 加工方法や工具形状の検討は技術部門が中心となり、営業は同行や情報共有を通じて関与する。顧客の将来技術に関する情報収集等も技術部門で行っている。
- 顧客で採用された工具は切り替わりにくい。過去には他社への販売を制限する契約を求められ、顧客専用の型番となる場合もあったが、こうした例は最近減っている。
- 営業としては専用型番を増やさず、なるべく複数顧客で同じ製品を使えるようにしたい。型番を集約することで、作りやすさ、納期対応、在庫の共用につなげたいとの考えが示された。
- 試験項目の調整は技術部門が担当している。

### 3.6 営業情報の共有と見積業務の課題

営業活動の日報を登録し、営業部門以外の社員も閲覧・顧客別検索ができる仕組みがある。また、Copilotによる情報検索の活用も始まっている。一方で、必要な情報の保管場所・参照手段が分散していることが課題となっている。

| 情報 | 現状・参照先の例 |
| --- | --- |
| 価格情報 | 見積書、過去の取引情報等 |
| 販売実績・原価 | AS系の基幹システム。情報によって参照の入口が異なる |
| 市場シェア等 | Excelで作成。十分に共有されていないものもある |
| 顧客情報・営業活動 | 営業日報、担当者が持つ資料等 |
| 集計・分析 | 部門・担当者ごとのツール。存在を他部門が知らない場合がある |

- 単価を決めるには、市場価格、関連顧客の単価、過去実績、数量別の原価等、多くの情報が必要となる。必要に応じて技術部門へ原価見積りを依頼し、承認の根拠をそろえるため、情報収集に時間がかかっている。
- 材料調達、生産数量、製造条件等も原価に関わるため、見積業務は営業内の情報だけでは完結しない。
- 望ましい姿として、7桁の製品コードを入力すれば、どの市場・顧客に、いつ、何本、いくらで販売したか、原価や現在の生産状況等をまとめて参照できる仕組みが挙げられた。
- 出荷量等の情報自体は既存の仕組みで取得できるが、各人が異なるツールや見方を使っている。他部門で使われる便利なツールを知らず、昔からのツールを継続使用する場合もある。
- 各課・子会社等がシステム開発部門へ個別に依頼し、年間の計画に沿ってツールを作る取り組みがあるが、成果が依頼元以外に知られていない場合がある。
- 一方、輸出先の国によって必要書類・ルールが異なるため、国別のツールが必要となる事情もある。
- 社内からは、基幹システムと既存ファイル等の情報を結合することで実現できる可能性があるとの意見が出た。具体的な方式・実現性は未検証である。

### 3.7 市場調査・引き合い・案件管理

- 市場調査は半年に1回実施しており、シェア調査と市場動向の把握を行っている。
- 引き合いはホームページや顧客訪問等を通じて入るが、管理方法の統一的な決まりはなく、基本的に担当者が対応している。日報に記載されていなければ、周囲から把握しにくい。
- 新規提案案件の件数や進捗を部門全体で集計する管理は十分に行われておらず、担当者と上司が把握する形が中心である。
- 海外では、駐在する技術担当者が顧客ごとの評価内容、期限、サンプル等をExcelで管理し、営業担当者と共有している例がある。
- SFA等の専用システムによる案件管理は行っていない。

### 3.8 品質クレーム・技術問い合わせへの対応

- 品質クレームは営業が窓口となり、品質保証・技術・工場と連携して内容を調査する。
- 技術的な問い合わせを受けた場合は「調査依頼書」を出し、担当部門へ対応を依頼する。回答・技術評価を含め、案件のクローズまで対応している。
- 依頼は主にワークフローで申請しているとの説明があったが、廣島部長自身は現在の詳細運用をその場で確認できていない。
- 対応履歴は残っているが、その蓄積が今後の開発にどう活用されているかは、営業側からは分からないとのことだった。

### 3.9 納期回答・計画変更の負荷

- 現在、営業で最も工数がかかっているのは納期調整であり、生産管理も即答できない状況にある。代理店・顧客からの不満や催促への対応も発生している。
- 品目によって「明日出せる」ものから「4か月かかる」ものまであり、顧客が希望する納期との隔たりが大きい。
- 急ぎの依頼を既存計画へ割り込ませるには、他の計画を動かす必要がある。人が考えて手作業で調整し、1日に何十件も対応しているとの説明があった。
- 午前の会議で出た急な型番変更について、廣島部長からは、急ぎ品の割込みに伴って他の計画を変更する必要が生じているのではないかとの見方が示された。
- 社内からは、生産管理でAsprovaに予定を登録しているとの補足があったが、計画を立てる期間や具体的な運用は確認できていない。
- 顧客・代理店との間には注文等の締切に関する営業ルールがある。一方、社内システムへの入力時期や生産管理側の計画変更ルールの詳細は、廣島部長の把握範囲外だった。
- JMACからは、納期・注文の確定時期や特急対応の受入枠等をルール化した上で、システムを活用する事例が紹介された。自社への適用や具体的な基準は決定していない。

### 3.10 少量品・赤字型番の継続判断

- 年間数百本程度しか出ない製品や、売っても赤字となる製品があり、工場の生産効率という点では課題がある。
- 一方、国内のPCB工具メーカーとしてカタログのシリーズを欠かさず供給すべきという考えや、その工具がないと顧客が困る事情もあり、採算だけで廃止を決めることは難しい。
- 新事業の開始・撤退や製品をやめる判断は、最終的にトップへ相談して決める。継続・撤退の判断基準が明文化されているわけではなく、始める一方で「どうなったらやめるか」が十分に定まっていないことは問題との認識が示された。
- 製品ごとの担当部門が状況を確認し、PCB工具は第一営業部、エンドミルは第二営業部が関わる。
- 赤字型番の報告は毎月あり、対応を検討している。ただし、個々の不良発生数等の詳細まで示されるわけではない。
- 新製品では、立上げ時の少量生産で赤字でも、将来の数量増加によって採算を確保する想定で開始する場合がある。コーティングを例に、1回500本の処理が将来1万本になれば採算が変わるとの説明があった。
- 将来も数量が増えなかった場合の扱いが課題となるが、そのような例が多数あるという説明ではない。数量は考え方を示す例示である。
- JMACからは、ロット数量等に応じた継続・廃止基準の整理も検討視点として挙げられた。

### 3.11 2030年に向けた備えと本プロジェクトへの期待

- 廣島部長は、2030年頃まで売上が従来にないペースで伸びる可能性を見ている。営業業務は本社で現物を扱うよりデータ処理が中心であり、単純な数量増加であれば、大幅な増員をせず売上2倍・3倍に対応するイメージを持っている。
- ただし、現行システムの容量・速度・効率で増加に対応できるかは不明であり、事前の精査・準備が必要である。100万本が300万本になっても出荷処理できるか、という例が挙げられた。
- 納期調整は数量に応じて増えるため、単純なデータ処理とは別に負荷への対応を考える必要がある。
- 新しい加工方法やコーティングによる工具寿命の変化があり、基板需要の拡大が、そのまま販売するドリル本数の増加につながるかは読みづらい。
- レーザー加工の登場時にもドリル需要の消失が懸念されたが、結果として加工方法のすみ分けが進んだという経験が共有された。
- 外部の視点で現在の営業業務の妥当性・効率を見直し、受注や注文獲得の段階から工場・グループ全体へつながる仕組みを考えてほしいとの要望があった。
- 工場への要望として、無理な増産を求めるよりも、休みを取り、健康に気を付けて持続的に働いてほしいとの思いが述べられた。
- 部門間で互いに要望を強く伝えることや、人員のローテーションが比較的少ないという認識も共有された。
- JMACからは、夜勤の削減や少人数での操業、取り扱う案件・品目の見直しと高付加価値品への注力も、持続的に働ける工場を考える視点として挙げられた。

## 4. 今後の調査・討議で確認する論点

以下は発言から整理した継続確認事項であり、本インタビューで担当者・期限を確定した宿題ではない。

| 論点 | 確認・検討する内容 |
| --- | --- |
| 営業情報の参照・共有 | 価格、販売実績、原価、市場情報等の所在と参照方法。製品コードを起点に必要情報をまとめて参照するための連携範囲 |
| 既存ツールの共有 | 各部門・子会社のツールの把握、共通化できる機能と国別要件への対応 |
| 納期回答・計画変更 | 受注から回答までの実務、顧客・代理店との締切、社内入力・計画確定・割込み調整のルール、Asprovaの運用実態 |
| 成長に対応するシステム | 取扱量が2倍・3倍になった場合の処理能力、応答時間、受注・出荷業務への影響 |
| 顧客情報と開発の連携 | 引き合い・評価案件の管理、調査依頼書の運用、対応履歴の蓄積と開発への活用状況 |
| 品目別の採算・継続判断 | 赤字型番の評価方法、数量と原価の関係、ラインナップ維持の必要性、継続・撤退の判断基準 |
| 市場・需要の見通し | 注力市場の範囲とシェア、需要情報を供給能力・投資判断へつなげる流れ、加工方法・工具寿命の変化 |
