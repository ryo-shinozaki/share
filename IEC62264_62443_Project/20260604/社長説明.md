# 工場標準化・セキュリティ強化プロジェクト 社長説明

## 目的

横河デジタル様との6月4日打合せ結果を報告し，3,600万円見積に対する費用切り詰め方針と，今後の進め方について社長の確認をいただく。

説明時間は5分を想定する。

## 1. 要旨

- 横河デジタル様の提案内容は，当社の課題認識と大きくずれていない。
- 3,600万円は大きな金額であり，5月8日打合せでご指示いただいた通り，費用の切り詰めは必要であるとお伝えした。
- ただし，単純に作業を半分にするだけでは，最終的な全体費用が下がらず，単なる先送りになる懸念がある。
- 対象範囲，作業分担，当社側で担える作業を詰め，費用を下げられる余地を明確にするための作業を行っている。
- 当社側のIEC 62264, 62443の経験不足により，当社側の責任が大きくなるとプロジェクトそのものの進捗に懸念がある。
- 社長の考える費用感を横河デジタル様へお伝えし，社長と横河デジタル様との面談をお願いしたい。

## 2. 当社課題

スマートカンパニーとは，理想的には，

- 受注から出荷までがすべて自動化されている
- このプロセスと，プロセスそのものが自律的に改善される

と解釈する。この状態を達成するために，「工場データを経営判断や生産改善に使える状態にすること」だと整理した。

主な課題は以下の通り。

- 設備データが十分に取れていない。
- 取れているデータも，設備・工程・部署ごとに形式や粒度がばらばらである。
- 生産能力，稼働率，OEE等を共通指標で比較できる状態になっていない。
- AS400にはERP，MES相当機能，現場向け機能が長年積み重なっており，全体像や機能の切り分けが分かりにくい。
- IT部門，生産技術部門，製造部門の間で，OTネットワークや設備データを誰がどこまで管理するかが明確でない。
- セキュリティ面では，工場ネットワークや設備資産を正確に把握できていない。

## 3. 横河デジタル様の見解

横河デジタル様からは，現状把握を行うことで，以下を明確にする必要があるとの説明を受けた。

- AS400上にどの機能があり，MES/MOM相当機能として何が足りないか。
- 工場業務とシステム，設備データがどのようにつながっているか。
- 設備データをどの粒度で取得し，どこに蓄積し，どのKPIに使うべきか。
- 工場ネットワーク，島ハブ配下の設備，古いOSやPLC等の資産がどのような状態か。
- セキュリティ対策の前提となる資産一覧やネットワーク構成をどう整備すべきか。

横河デジタル様も，3,600万円の金額が大きいことは認識している。ただし，金額だけを下げるために作業を細切れにすると，中途半端な成果で止まるリスクがあるとの意見であった。

## 4. 費用切り詰めに関する考え方

費用を切り詰めるためには，単純な値引き交渉ではなく，作業範囲と役割分担を見直す必要がある。

現時点で考えられる切り詰め方は以下である。

1. **調査対象を絞る**
   - 初期対象は長岡工場のPCBドリルを軸にする。
   - 本社業務全体には広げず，工場業務から関係する範囲だけを見る。
   - 設備機械のBOM/PLM等，今回の主目的から外れる領域は深追いしない。

2. **当社側でできる作業を増やす**
   - AS400関連資料，Excel連携，設備データ取得状況，島ハブ・設備情報の棚卸しを当社側で進める。
   - 横河デジタル様には，調査観点，標準との照合，評価，整理方法の助言を重点的に依頼する。

3. **ネットワーク調査の粒度を調整する**
   - 理想は全設備の洗い出しだが，初期段階では代表的な島ハブや設備カテゴリを選定して調査する案を検討する。
   - ただし，セキュリティ上のリスク把握に必要な範囲は残す。

4. **現状把握前の準備ステップを設ける**
   - すぐに3,600万円の発注判断をするのではなく，まず調査範囲，当社側工数，横河デジタル様の支援範囲を詰める。
   - その結果をもとに，正式な費用圧縮案を再提示してもらう。

「困ったときだけ相談を受ける」といったアドバイザ契約で大幅に費用を抑えることはできるが，当社側のIEC 62264, 62443の経験不足のために，この方法ではプロジェクトを遂行できないと考えている。

## 5. 社長に確認したいこと

以下の方針で進めてよいかを確認したい。

費用切り詰めを前提に，

- 横河デジタル様の提案をベースに検討を継続する。
- 当社側で担える棚卸し作業を増やし，横河デジタル様の支援範囲を絞る方向で再見積を依頼する。
- 初期対象は長岡工場PCBドリル，AS400/MES相当機能，設備データ，工場ネットワークを中心に絞る。(L4を含まない)
- 7月開始にはこだわらず，費用・範囲・体制が整理できた段階で着手時期を決める。
- 社長と横河デジタル様との面談の機会を設け，提案について議論の場を設けたい。

## 6. 想定される質問と回答

### Q1. なぜ外部コンサルが必要なのか

当社だけでは，IEC 62264，IEC 62443，MES/MOM，製造KPI，OTセキュリティの標準に照らして，何が足りないかを客観的に整理することが難しいため。特に，設備データ，工場ネットワーク，AS400機能が絡むため，標準知識と製造システムの両方が必要になる。

また，当社側のIEC 62264，IEC 62443の経験が不足しているため，当社が主導し，横河デジタル様には困ったときだけ相談する進め方では，プロジェクトの進捗に懸念がある。

### Q2. 3,600万円は高すぎないか

高いと認識している。そのため，そのまま進めるのではなく，対象範囲を長岡工場PCBドリル中心に絞り，当社側でできる棚卸し作業を増やして，費用を下げる余地を確認する。

一方で，単純に作業を半分にするだけでは，後工程に必要な調査が残り，全体費用が下がらず先送りになる懸念がある。費用を下げるには，削る作業と残す作業を見極める必要がある。

### Q3. どこまで費用を下げられるのか

現時点では未確定。下げるには，何を当社側で実施できるか，横河デジタル様に何を依頼するかを具体化する必要がある。

初期対象は長岡工場PCBドリル，AS400/MES相当機能，設備データ，工場ネットワークに絞り，本社業務全体やL4領域は含めない前提で再整理する。そのうえで，社長の考える費用感を横河デジタル様へ伝え，再見積につなげたい。

### Q4. 今やらないと何が困るのか

生産量を増やしたい局面で，設備能力，稼働率，ボトルネック，改善効果を共通指標で把握できない。設備を増やしても，実際にどこが詰まっているか，どの投資が効くかを判断しにくい。また，工場ネットワークやOT資産が把握できていないと，セキュリティ対策も後手になる。

### Q5. AS400を置き換える話なのか

違う。AS400は当面使い続ける。今回の目的は，AS400上の機能，現場業務，設備データ，周辺システムの関係を整理し，将来どこを残し，どこを外部化・追加実装するか判断できる状態にすることである。

### Q6. 7月から始める必要があるのか

7月開始にはこだわらない。費用，範囲，体制が整理できた段階で着手時期を決める。まずは発注判断ではなく，費用切り詰めを前提とした再見積と，社長と横河デジタル様との面談を進めたい。
