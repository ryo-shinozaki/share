# コンサルタント比較表（テンプレート）

この比較表は「AS/400を中核としたIEC 62264(ISA-95)／IEC 62443導入構想」プロジェクトに沿って、候補コンサルタントを同一軸で評価するためのテンプレートです。必要に応じて項目を追加・削除してください。

---

## 0. 活用手順（おすすめ）

1. 「重要度」を合意（高／中／低）。必要であれば重み付け（例：高=3／中=2／低=1）を設定する  
2. 面談・提案書から情報を収集し、「会社別サマリー」と「比較表」に転記する  
3. 重要度×スコアで合計点を算出し、定量で比較する  
4. 「懸念点」「前提条件」を見直し、追加質問や交渉材料にする  
5. ステアリング向けに、上位候補の差分と判断理由を要約する

## 4. 重要質問（面談・RFP確認用）

- AS/400前提でのIEC 62264(ISA-95)設計経験はありますか？
- IEC 62443-2-1/3-2/3-3の具体的な成果物例を提示できますか？
- OT本番と開発・実験ゾーンを分離した実装経験はありますか？
- ネットワーク分割の際の運用ルールまで提案可能ですか？
- 年度1の成果物と体制（人員・稼働率）はどの程度ですか？
- 価格見積もりの前提条件（範囲外、追加費用）は何ですか？
- 海外拠点展開の支援可否と体制は？
