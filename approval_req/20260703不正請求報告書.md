# Anthropic社生成AI利用に関する不正請求のご報告

2026年7月3日

渡邉社長  
中島専務

生産技術部  
篠﨑 亮

## 1. 要旨

当社の生成AI活用環境として利用しているAnthropic社のサービスに関連し、私個人のクレジットカードに対して、身に覚えのない請求が発生しました。

不正請求と認識している金額は、外貨合計15,936.45 USD、円貨合計2,641,863円です。

本件については、2026年6月18日にクレジットカード会社へ不正請求として申告し、同日クレジットカード番号を変更しました。また、Anthropic社へも請求取り消し、原因究明、アカウント復旧を依頼しています。

2026年6月19日、クレジットカード会社から、不正請求分2,641,863円の引き落としは停止する旨の連絡を受けています。現時点では、Anthropic社側での調査および紛争処理の完了を待っている状況です。

## 2. 背景

当社における生成AI活用を推進するため、Anthropic Platformにアカウントを作成し、社員がAI CHAT V2を通じてAPI経由でClaudeを利用できる環境、およびVSCodeからAPI経由でClaude Codeを利用しソースコード生成を行える環境を整備していました。

Anthropic社への支払いはクレジットカードが基本となりますが、当社ではコーポレートカードを保有していないため、これまでは私個人のクレジットカードで支払っていました。

また、Anthropic Platform用のアカウントには、民間ISPのメールアドレスを新規取得して使用していました。これは、私の社用メールアドレスが名刺等で広く知られていること、および個人クレジットカードの決済情報を社用メールアドレスに紐付けることを避けるためです。

Anthropic Platformの利用料はプリペイド方式で、トークン使用量に応じてチャージ残高が減少します。残高が0 USDに近づいた時点で、都度500 USDをチャージして運用していました。

## 3. 発生経緯

### 2026年6月10日

AI CHAT V2で以下のエラーが表示され、Claudeを利用できなくなりました。

> [ERROR] ストリーミングエラー: Anthropic HTTP 400 [invalid_request_error]: You have reached your specified API usage limits. You will regain access on 2026-07-01 at 00:00UTC.

Anthropic Platformでは月間使用上限を2,000 USDに設定していたため、当初はこの上限に達したものと考えました。

同日、Anthropic Platformのアカウントを確認したところ、クレジット残高が0 USDとなっていたほか、全API Key、請求履歴、使用状況の情報が消失していました。実質的に、アカウントが初期状態に戻ったような状態でした。

### 2026年6月11日

当社の生成AI利用を停止したままにできないと判断し、500 USDを追加チャージしました。

一方で、API Keyの流出または不正利用の可能性も懸念されたため、月間使用上限を10 USDに引き下げ、残高が消費されるか監視しました。2026年6月20日までの間、この追加チャージ分の消費は確認されませんでした。

### 2026年6月18日

私のクレジットカードに対し、Anthropic社から身に覚えのない請求が発生していることを確認しました。請求額は、外貨合計15,936.45 USD、円貨合計2,641,863円です。

同日、クレジットカード会社へ不正請求として申告し、直ちにクレジットカード番号を変更しました。

また、Anthropic社へ不正請求の発生を報告し、請求取り消し、原因究明、アカウント復旧を依頼しました。

### 2026年6月19日

クレジットカード会社から、不正請求分2,641,863円の引き落としは停止する旨の電話連絡を受けました。

### 2026年6月20日

2026年6月11日に追加チャージした500 USDについて、Anthropic社へ返金を依頼し、同日承認されました。

なお、2026年7月3日現在、この500 USD分、税込550 USDは私のクレジットカード口座へ着金していません。本件は不正請求とは別件ですが、不正請求に関する紛争処理が完了するまで、返金処理にも時間を要する可能性があります。

### 2026年6月25日

クレジットカード会社へ異議申立書を郵送しました。

### 2026年7月1日

Anthropic社から、2026年6月10日に何者かにより不正利用されたと考えられる費用の不足分として、75.47 USDの請求がありました。支払期限は2026年7月15日とされています。

既にクレジットカード番号を変更しているため、当該請求の引き落としは実行されない見込みです。

この請求については、直ちにAnthropic社へ取り下げを依頼しましたが、Anthropic社からは、紛争が解決するまでは対応できない旨の回答を受けています。

## 4. 現在の状況

現在の状況は以下の通りです。

- 不正請求額は、外貨合計15,936.45 USD、円貨合計2,641,863円です。
- クレジットカード会社には不正請求として申告済みです。
- クレジットカード番号は変更済みです。
- クレジットカード会社から、不正請求分2,641,863円の引き落とし停止連絡を受領済みです。
- クレジットカード会社へ異議申立書を郵送済みです。
- Anthropic社へ、請求取り消し、原因究明、アカウント復旧を依頼済みです。
- 2026年6月11日に追加チャージした500 USD、税込550 USDは返金承認済みですが、2026年7月3日現在、未着金です。
- 2026年7月1日に追加で請求された75.47 USDについては、Anthropic社へ取り下げを依頼済みですが、紛争解決まで対応不可との回答を受けています。

## 5. 今後の対応

本件については、引き続きクレジットカード会社およびAnthropic社と連絡を取り、不正請求の取り消し、原因究明、返金処理、アカウント復旧の状況を確認します。追加の請求や照会が発生した場合は、速やかに内容を確認し、必要な対応を行います。

会社として継続的に生成AIを活用していくためには、決済手段および契約主体を個人に依存させず、会社管理のもとで安全に運用できる体制へ移行することが望ましいと考えます。

Anthropic Platformの利用継続にあたっては、国内で信頼できる請求代行または法人向けの支払方法が利用できるかを確認します。

以上、ご報告いたします。
